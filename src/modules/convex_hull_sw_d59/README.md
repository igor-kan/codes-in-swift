# Monotone Chain 2D Integer Convex Hull Solver (`convex_hull_sw_d59`)

> Category: **Computational Geometry** | Language: **Swift 5.10+**

## Overview

Constructs counter-clockwise minimal convex hulls over 2D integer coordinates cleanly stripping interior collinear and contained points.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Bounding square with interior point preserves strictly 4 hull boundary corners.
