# Stoer-Wagner Global Undirected Min-Cut Solver in Swift (`stoer_wagner_mincut_swift`)

> Category: **Graph Cuts** | Language: **Swift 5.10+**

## Overview

Computes the exact global minimum weight cut over undirected weighted graphs via Stoer-Wagner contraction phases.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(V^3) maximum-adjacency phase contraction` |
| **Space Complexity** | `O(V^2)` |

## Mathematical & Safety Invariants

- Global min-cut weight <= minimum weighted vertex degree.
