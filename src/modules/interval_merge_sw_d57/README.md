# Closed Interval Union Merger & Measure Calculator (`interval_merge_sw_d57`)

> Category: **Geometry & Intervals** | Language: **Swift 5.10+**

## Overview

Merges overlapping/touching integer spans into minimal disjoint ascending segments cleanly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Merged spans stay sorted and strictly non-overlapping.
