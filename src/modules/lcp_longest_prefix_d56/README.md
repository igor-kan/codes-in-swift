# Kasai Linear Longest Common Prefix Array Engine (`lcp_longest_prefix_d56`)

> Category: **Suffix Indexing** | Language: **Swift 5.10+**

## Overview

Constructs exact adjacent longest-common-prefix lengths over suffix order permutations in linear time via rank-pointer shrinkage.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Distinct substrings count equals N*(N+1)/2 - sum(lcp).
