# Linear-Space Levenshtein Edit Distance Evaluator (`edit_distance_hirsch_d56`)

> Category: **Dynamic Programming** | Language: **Swift 5.10+**

## Overview

Computes exact single-character insert/delete/replace Levenshtein distance across Unicode scalar slices using a rolling 1D DP row.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(M * N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Levenshtein distance is symmetric and obeys d(a, a) == 0 cleanly.
