# Lossless Run-Length Tuple Encoder & Expander (`run_length_codec_d56`)

> Category: **Sequence Compression** | Language: **Swift 5.10+**

## Overview

Compresses contiguous identical byte runs into (byte, count) tuples and expands them back into the original byte vector.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(K runs)` |

## Mathematical & Safety Invariants

- Decoding compressed runs restores original byte array bit-for-bit.
